# AI News Daily

A polished HTML blog page summarizing the day's top AI stories from India and across the globe.

## About

AI News Daily gathers the latest AI news every morning and publishes a self-contained HTML blog page with:
- India-focused stories first, then global developments
- Categories: India, Global, Research, Policy
- Interactive features: live search with highlighting, filter pills, bookmarks, expandable details
- Light parchment theme with Lora + Inter + JetBrains Mono typography
- Reading progress bar, back-to-top, toast notifications, staggered fade-up animations
- Keyboard shortcuts: `/` to search, `Escape` to clear
